【快速啟動方式（3 種方式任選一種即可）】
----------------------------------------------------------------------

方法 1：直接雙擊「index.html」（最簡單）
  - 直接點選兩下 index.html。
  - 支援 Google Chrome、Microsoft Edge、Mozilla Firefox、Safari 等所有現代瀏覽器。
  - 無需連上網際網路，無須安裝任何伺服器環境。

方法 2：Windows 使用者雙擊「一鍵開啟-Google瀏覽器.bat」
  - 專為 Windows 設計，點擊兩下即會自動呼叫電腦中的 Google Chrome 開啟平臺。
  - 或點擊「start-offline-windows.bat」。

方法 3：Mac / Linux 使用者執行腳本
  - 開啟終端機（Terminal）進入本解壓資料夾。
  - 執行：chmod +x start-offline-mac-linux.sh && ./start-offline-mac-linux.sh
  - 或直接在 Finder / 檔案管理員中點兩下 index.html 即可。

【若 Google Chrome 仍出現問題的疑難排解】
----------------------------------------------------------------------
1. 為什麼舊版本 Chrome 會打不開？
   舊版網頁因為將 script 與 css 分成多個檔案，Chrome 出於嚴格的安全沙箱機制，
   在直接點擊 HTML (file:// 協定) 時會封鎖模組腳本載入（CORS 限制）。
   本最新版本已徹底內聯封裝為單一自包含檔案，不再需要載入任何外部檔案！

2. 若您的 Windows 提示「Windows 已保護您的電腦」：
   這是 Windows 下載 ZIP 檔案時的常見安全防護機制（SmartScreen）。
   請點擊「其他資訊」->「仍要執行」即可正常啟動。

3. 也可以直接使用 Microsoft Edge 開啟：
   在 index.html 上按滑鼠右鍵 ->「開啟檔案」-> 選擇「Microsoft Edge」或「Google Chrome」。
